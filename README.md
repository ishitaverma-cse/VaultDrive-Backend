# 🔐 VaultDrive — Backend

## 📌 Project Overview

VaultDrive is a full-stack file management system that allows users to securely upload, store, manage, and access their files.

This repository contains the backend of the VaultDrive application.

## 🛠️ Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Supabase
- JavaScript
- REST APIs
